Exercises

Introduction to generalized linear mixed models

These exercises follow the sample session step by step. The code runs in your browser: no installation needed. Type your code in the boxes and press Run Code. Stuck? Open the Hint tab, and compare your answer with the Solution tab.

Before you start
  • The first time, loading R and the packages ggplot2, dplyr and lme4 takes up to a minute. Wait until the boxes are ready.
  • Two datasets are already loaded:
    • lizard: 102 lizards from 29 mothers, with mother, sex (Male or Female) and dors (number of dorsal scales). Data courtesy of Prof. Geert Verbeke (KU Leuven).
    • learn: a simulated learning task, 30 individuals (id) doing 10 trials per session over 8 sessions (session), with correct (1 or 0). It is the same simulated dataset as in the slides.

Part 1: Look at the data first

Exercise 1.1: How is the data grouped?

How many lizards and how many mothers are in lizard? Fill in the blanks.

  • Exercise
  • Hint
  • Solution

nrow() counts the rows of a data frame. n_distinct() from dplyr counts the different values in a column. Which column identifies the mothers?

nrow(lizard)
n_distinct(lizard$mother)

102 lizards from 29 mothers: on average about 3.5 siblings per mother.

Exercise 1.2: Plot before you model

Complete the code to plot the number of dorsal scales for each mother, coloured by sex. What do you notice?

  • Exercise
  • Hint
  • Solution

The x-axis shows the grouping (mother), the y-axis the response (dors), and the colour the predictor of interest (sex).

ggplot(lizard, aes(x = mother, y = dors, colour = sex)) +
  geom_point(size = 2.5, alpha = 0.8) +
  labs(x = "Mother", y = "Dorsal scales") +
  theme_minimal()

Mothers differ a lot in their typical number of scales, and within a mother, males tend to have more scales than females. Siblings are more alike than unrelated lizards.

Part 2: Accounting for the grouping

Exercise 2.1: Ignoring the mothers

Compare males and females with a two-sample t-test that assumes equal variances. Is there evidence of a difference?

  • Exercise
  • Hint
  • Solution

Use t.test() with a formula response ~ group, the data argument and var.equal = TRUE.

t.test(dors ~ sex, data = lizard, var.equal = TRUE)

\(p \approx 0.10\): no clear evidence of a difference. But the test treats all 102 lizards as independent (df = 100), which they are not.

Exercise 2.2: Your first linear mixed model

Fit a linear mixed model for dors with sex as a fixed effect and a random intercept for mother. Then compare the sex effect with the one from lm(dors ~ sex).

  • Exercise
  • Hint
  • Solution

A random intercept for mother is written (1 | mother) and added to the formula like any other term: dors ~ sex + (1 | mother).

fit_lm  <- lm(dors ~ sex, data = lizard)
fit_lmm <- lmer(dors ~ sex + (1 | mother), data = lizard)

summary(fit_lm)$coefficients
summary(fit_lmm)$coefficients

The mixed model compares lizards within mothers: the sex effect becomes larger (about \(-0.83\) scales for females) and its standard error smaller, so the t value is now about \(-2.6\).

Note that lme4 does not print p-values. The lmerTest package adds them, as in the slides.

Exercise 2.3: How alike are siblings?

Extract the variance components from fit_lmm and compute the intraclass correlation (ICC).

  • Exercise
  • Hint
  • Solution

The ICC is the share of the total variance that lies between mothers: \[\rho = \frac{\sigma^2_{mother}}{\sigma^2_{mother} + \sigma^2}\]

fit_lmm <- lmer(dors ~ sex + (1 | mother), data = lizard)

vc <- as.data.frame(VarCorr(fit_lmm))
s2_mother   <- vc$vcov[vc$grp == "mother"]
s2_residual <- vc$vcov[vc$grp == "Residual"]

icc <- s2_mother / (s2_mother + s2_residual)
icc

\(\rho \approx 1.78 / (1.78 + 2.25) = 0.44\): about 44% of the variability in dorsal scales is due to the mother.

Part 3: When the response is binary

Exercise 3.1: Plot the learning curves

Compute the proportion of correct answers for each individual and session, then plot one line per individual.

  • Exercise
  • Hint
  • Solution

We want one proportion per individual (id) and session (session), and one line per individual.

learn_sum <- learn |>
  group_by(id, session) |>
  summarise(p = mean(correct), .groups = "drop")

ggplot(learn_sum, aes(x = session, y = p, group = id)) +
  geom_line(alpha = 0.5) +
  labs(x = "Session", y = "Proportion correct") +
  theme_minimal()

All individuals tend to improve, but they start at very different levels: another sign of grouped data.

Exercise 3.2: Fit a GLMM

Fit a logistic GLMM for correct with session as a fixed effect and a random intercept for id. Then compute the odds ratio per session.

  • Exercise
  • Hint
  • Solution

The formula is built just like in lmer(): correct ~ session + (1 | id). For a binary response, use family = binomial.

fit_glmm <- glmer(correct ~ session + (1 | id), family = binomial, data = learn)

summary(fit_glmm)

exp(fixef(fit_glmm))

The estimate for session is on the log-odds scale. exp() turns it into an odds ratio: for a typical individual, the odds of a correct answer are multiplied by this factor in each session. The Std.Dev. of id under Random effects shows how much individuals differ.

Exercise 3.3: Challenge: typical individual or population average?

Using fit_glmm, compute the probability of a correct answer in session 8 (a) for a typical individual (\(b_i = 0\)) and (b) averaged over the population of individuals. Why do they differ?

  • Exercise
  • Hint
  • Solution

Add each simulated random intercept b_draw to the linear predictor, transform with plogis(), and take the mean() of the resulting probabilities.

fit_glmm <- glmer(correct ~ session + (1 | id), family = binomial, data = learn)
beta <- fixef(fit_glmm)
sd_b <- as.data.frame(VarCorr(fit_glmm))$sdcor[1]

p_typical <- plogis(beta[1] + beta[2] * 8)

b_draw <- rnorm(10000, mean = 0, sd = sd_b)
p_average <- mean(plogis(beta[1] + beta[2] * 8 + b_draw))

c(typical = p_typical, average = p_average)

The population average is closer to 50% than the typical individual. Averaging S-shaped curves that are shifted left and right gives a flatter curve: in a GLMM, the fixed effects describe the typical individual, not the population average.
